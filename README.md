🧿 Arbiter

A private AI workspace you can host yourself in under 5 minutes.

---

🚀 Deploy (Step-by-Step, No Guessing)

Step 1 - Create a GitHub account

If you do not have one:
https://github.com/signup

---

Step 2 - Create a new repository

1. Go to: https://github.com/new
2. Name it anything you want, for example: "arbiter"
3. Make sure it is Public
4. Click Create repository

---

Step 3 - Upload the app

On your new repo page:

1. Click Add file then Upload files

2. Drag and drop your file named:
   
   "index.html"

3. Scroll down and click Commit changes

You should now see "index.html" listed in your repository.

---

Step 4 - Turn on GitHub Pages

1. Click Settings at the top of the repo
2. Click Pages in the left sidebar

Set the following:

- Source: Deploy from branch
- Branch: "main"
- Folder: "/ (root)"

Then click Save

---

Step 5 - Open your app

After a few seconds, GitHub will show a link like:

"https://YOUR_USERNAME.github.io/arbiter/"

Click it.

---

🎉 What you should see

- A dark screen
- “Arbiter” title
- Passphrase input

If you see that, it is working.

---

🔑 First-time setup

Required

- Passphrase
  This is your local lock for the app.

- OpenRouter API key
  Get one here:
  https://openrouter.ai/settings/keys

Optional

- Supabase URL and key
  Use this only if you want sync across devices.

---

❗ Common mistakes

Page shows 404

Wait 30 seconds, then refresh the page.

Blank white page

Make sure the file is named exactly:

"index.html"

Changes are not showing

Do a hard refresh:

"Ctrl + Shift + R"

---

🧠 What this is

- A full app in one file
- Runs entirely in your browser
- No server required
- Your data stays with you unless you choose to use Supabase sync

---

⚡ TL;DR

"Upload index.html -> enable GitHub Pages -> open the link -> done"
